## 🚀 Filosofía de Trabajo

* **El contexto manda:** Antes de tirar la primera línea de código, analizo a fondo el entorno del proyecto. Entiendo las reglas de negocio, las restricciones técnicas (APIs cerradas, normativas) y los límites del entorno. La solución debe nacer del problema, y no al revés.
* **Elección de stack con propósito:** Una vez que entiendo el panorama, escojo las tecnologías, plataformas y librerías ideales para el desafío. Gracias a mi experiencia con distintos entornos, adapto el stack a las necesidades reales del producto, sin atarme a una sola herramienta.
* **Pragmatismo en el desarrollo:** Priorizo arquitecturas y soluciones que agilicen las entregas manteniendo altos estándares de calidad. Mi objetivo es optimizar recursos y tiempo de manera inteligente, evitando los atajos que comprometan el futuro del proyecto.
